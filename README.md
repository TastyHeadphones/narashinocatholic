# カトリック習志野教会ウェブサイト（WordPress）

「Narashino Church Website Redesign」のデザインを WordPress で実装したサイトです。内容は現在の公式サイト（https://www.narashinocatholic.com/ ）から引き継いでいます。

## 構成

| パス | 内容 |
| --- | --- |
| `wp-content/themes/narashino-catholic/` | テーマ本体。トップページ、下層ページ、お知らせ、お問い合わせフォーム、教会情報の設定画面、Google マップの埋め込み |
| `seed/pages/` | 固定ページの本文（HTML）。デザインのコンポーネント（カード、一覧、年表、質問と回答など）で書かれています |
| `seed/photos/` | 写真（司祭の紹介の写真、50周年記念ミサの写真 2 点） |
| `seed/notices.json`, `seed/photos.json` | お知らせの内容、写真の定義 |
| `seed/seed.php`, `seed/setup.sh` | 初期内容の投入と、WordPress のインストール |
| `docker-compose.yml` | ローカル開発用の環境（WordPress 7.1.4 / PHP 8.3 / MariaDB 11.8 / WP-CLI） |

## ローカルで動かす（Docker）

```bash
cp .env.example .env          # 管理者パスワードは必ず変更する
docker compose up -d
docker compose logs -f wpcli  # 「完了しました」と出たら準備完了
```

- サイト: http://localhost:8080/
- 管理画面: http://localhost:8080/wp-admin/

停止は `docker compose down`（データは残ります）。すべて初期化するには `docker compose down -v` を実行してください。

## Docker を使わずに動かす

PHP 8.1 以上（mysqli）、WP-CLI、WordPress 7.1.4 を用意し、テーマを `wp-content/themes/narashino-catholic` にリンクしてから次を実行します。

```bash
WP_PATH=/path/to/wordpress WP_URL=http://localhost:8080 sh seed/setup.sh
```

`setup.sh` は、WordPress のインストール（未実施の場合）、日本語化、テーマの有効化、パーマリンク設定、`seed/seed.php` の実行を行います。何度実行しても安全です。

## 内容の更新

- **教会情報**（設定 > 教会情報）: 住所、電話・FAX、ミサの時間、ゆるしの秘跡、清掃の日時、道順、お知らせバーの文言。ミサの時間は毎月のお知らせで変わるため、変更があれば必ずここも更新してください。
- **固定ページ**: 本文は HTML で書かれています。管理画面の「テキスト」タブで編集してください（ビジュアルエディタで保存すると、カードや一覧のレイアウトが崩れることがあります）。各ページの「英語の副題」は右側の欄で編集します。
- **お知らせ**: トップページには新しい順に3件を表示します。ラベル、英語の見出し・説明、注意の表示、関連リンクを設定できます。
- **司祭の紹介**のアイキャッチ画像が、トップページの司祭の写真になります。**司祭からの言葉**の抜粋（概要欄）が、トップページの紹介文になります。
- **メニュー**（外観 > メニュー）: 「ヘッダーメニュー」「フッターメニュー」。

## 画像と地図について

- **文字だけの画像は取り込んでいません。** 公式サイトでは、ミサの時間の掲示、毎月のお知らせ、年間典礼行事予定、聖書講座の案内、清掃の案内、英語の案内、年間移動祝日の表、秘跡の案内、司祭の紹介の質問と回答、司祭からの言葉、教会の歩みの年表などが画像で掲載されていました。これらは OCR（文字認識：tesseract の日本語・英語モデル）で読み取り、原本の画像と目視で照合してから、デザインのコンポーネントで組み直しています。
- **地図は Google マップで表示します。** 公式サイトの手描きの地図画像は使わず、本文の `[nc_map]`（英語ページは `[nc_map lang="en"]`）で埋め込みます。埋め込みは API キーを使わない共有用の形式です。
- **写真は 3 点だけです。** 司祭の紹介の写真（1200px）と、50周年記念ミサの写真 2 点。取り込みは外部のサイトからは行わず、`seed/photos/` のファイルを使います。
- **装飾はデザインに基づいて作成しています。** 夕暮れの教会、のれん、バラ窓、七宝模様、印章などは SVG と CSS で描き直し、テーマの `assets/svg/` に含めています。公式サイトのロゴ・見出し画像は使っていません。

## 初期内容の投入について

`seed/seed.php` は、ページ・お知らせ・メニューが**まだ無い場合だけ**作成します。既にあるものは上書きしません。管理画面で編集した内容は、再実行しても消えません。

初期内容に戻したい場合だけ、`NC_SEED_FORCE=1` を付けて実行してください。固定ページ・お知らせ・メニューは初期内容で上書きされます（教会情報の設定は残ります）。

```bash
docker compose run --rm -e NC_SEED_FORCE=1 wpcli
```

## お問い合わせフォームとメール

- フォームは教会情報の「メールアドレス」（空欄の場合は管理者のメールアドレス）宛に `wp_mail()` で送信します。内容はデータベースに保存しません。
- ローカル環境では実際にメールは届きません。本番ではSMTPの設定（メール送信プラグインなど）が必要です。

## 確認が必要な項目

- **日程と時間**: ミサの時間、年間典礼行事、聖書講座、毎月のお知らせの日程は、読み取った時点の案内です（「2026年2月現在」「2026年11月の予定」などと明記しています）。変更があれば教会情報とそれぞれのページを更新してください。
- **読み取りの確認**: OCR の結果は原本の画像と目視で照合していますが、数字・時刻・人名は教会事務室の原本と照合することをおすすめします。
- **プライバシーポリシー**: 公開前に教会で内容を確認してください。本サイトは Google Fonts と Google マップを読み込むため、その旨を記載しています。
- **メールアドレス**: 公式サイトに公開されていないため、空欄にしています（フォームは利用できます）。
- **英語の文面**: 英語の案内（Church Guide 2026年2月現在）と、デザインの文言に基づいています。
